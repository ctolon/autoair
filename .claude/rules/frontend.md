# Frontend (React, zustand)

Checks: skill `verify-frontend`; visible changes: skill `verify-ui-screenshots`; text: skill
`i18n-strings`; parameter widgets: skill `add-operator-widget`.

## Folders (`frontend/src`)

| Folder | Responsibility |
|---|---|
| `main.plugin.tsx`, `main.standalone.tsx`, `App.tsx` | entry points; the plugin build uses the Airflow UI's React/Chakra through `shims/` |
| `store/` | `builder.ts`: `useBuilder = create(temporal(...))` (zustand + zundo) |
| `canvas/` | React Flow canvas (`FlowCanvas.tsx`), memoised node views (`nodes/index.tsx`), ELK layout (`layout.ts`; ELK only in `layout.worker.ts`) |
| `panels/` | toolbar, palette, inspector (`panels/inspector/`), DAG settings, bottom panel |
| `widgets/` | parameter forms (`ParamsForm.tsx`, `fields.tsx`), pickers, CodeMirror editors (`widgets/code/`, lazy) |
| `lib/` | pure logic: `formSchema.ts` (param -> widget), `problemMessages.ts` (`problemText`), schedules, Jinja; `generated/` (by `scripts/gen_shared_constants.py`) |
| `lifecycle/` | deploy, runs, versions, imports: dialogs lazy-loaded by `LifecycleHost.tsx` |
| `codemode/` | full-screen code editing synced with the canvas; raw code DAGs (`RawCodeView.tsx`, `isRawDag`, `SPEC_ONLY_DIALOGS`) |
| `admin/`, `ai/`, `collab/`, `shell/` | admin panel (lazy), AI chat and troubleshooting (lazy), Yjs collaboration, platform shell, login, colour mode, command palette |
| `i18n/` | i18next instance and `locales/{en,tr}/*.json` |
| `api/` | `gen/` generated by `@hey-api/openapi-ts` from `frontend/openapi.json`; `setup.ts` hand-written client setup |
| `extensions/` | `registerNodeKind()` for custom node looks |
| `ui/ErrorBoundary.tsx` | per-area error boundary (`area`: builder, toolbar, palette, canvas, codeMode, bottomPanel, inspector, dialog) |

## Rules

- Strict TypeScript, eslint (`tseslint.configs.strict`, react-hooks), prettier (print width
  120). Function components and hooks; no class components except `ErrorBoundary`. Components
  `PascalCase` in `PascalCase.tsx`; hooks and stores `useX` (`useBuilder`, `useCanvasUi`,
  `useCodeMode`).
- zustand selectors return stable values: select primitives or existing objects; `useShallow`
  only when the selected items are themselves stable; never build new objects or arrays inside
  a selector (this caused a "Maximum update depth exceeded" crash; `src/store/selectors.test.ts`
  enforces it); derive with `useMemo`.
- Undo/redo: document changes go through `useBuilder`. History holds only `dag`, `nodes`,
  `edges` (zundo `limit: 100`, equality by `JSON.stringify`); drag bursts are grouped by
  `handleSet` (250 ms) into one entry; call `flushHistory()` before undo/redo/clear. Selection,
  UI and high-frequency state stay out of the builder store's history.
- Rendering never throws on invalid live input (wrong types, `null`, partial edits, unknown enum
  values): show a problem inline; areas sit inside `ErrorBoundary`.
- Colours only from Chakra semantic tokens (`fg.muted`, `bg.panel`, `border.emphasized`, ...),
  never palette literals. Inside Airflow the theme follows the host (`HOST_THEMED` in
  `shell/colorMode.ts`).
- Every user-visible string through `t(...)` with keys in `en` and `tr`. Backend problems are
  shown with `problemText(p)`, not the raw `message`.
- API calls only through the generated client (`src/api/gen` + `src/api/setup.ts`); the plugin
  and standalone modes mount the API under different prefixes, so never build URLs by string
  concatenation.
- Raw code DAGs (`raw_code`) get no spec-only entry points (`SPEC_ONLY_DIALOGS`).
- Lazy modules stay out of the entry chunk: CodeMirror, the LSP client, ELK, RJSF forms, admin
  and AI panels, lifecycle dialogs (`React.lazy` / dynamic `import()`). ELK is imported only in
  `canvas/layout.worker.ts` (`layout.test.ts` enforces it).
- React Flow: `nodeTypes`/`edgeTypes` are module-level constants; node views are `memo`ed; avoid
  store subscriptions that re-render every node on unrelated changes.
- vitest runs in Node by default; component tests opt in with `// @vitest-environment jsdom` and
  render through `src/test/render.tsx`.
- Check bundles with `npx vite build --mode standalone --outDir "$(mktemp -d)"` (and
  `--mode plugin`); ELK appears only in `assets/layout.worker-*.js`.
